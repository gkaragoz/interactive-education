# Bilim Atölyesi

An interactive 3D science learning site for Turkish students, aligned with the MEB curriculum and fully cited. The first module is cell biology; chemistry and physics follow. Learner-facing text is Turkish.

## Language

### Learning content

**Module**:
A self-contained science topic area shipped as one part of the site (first: Hücre / Cell).
_Avoid_: Course, unit, app

**Cell type**:
A kind of cell that can be explored in 3D (animal, plant, bacterium).
_Avoid_: Species, cell model

**Organelle**:
A named structure inside a cell type that has its own 3D model and info panel. Includes bacterial structures such as nucleoid and flagellum in this project's usage.
_Avoid_: Part, component, structure

**Level**:
A depth of explanation for the same organelle (a simpler and a more detailed Turkish text), mapped to school grades.
_Avoid_: Difficulty, grade, mode

**Kazanım**:
An official MEB learning outcome, identified by its program code, that an organelle's content supports.
_Avoid_: Objective, standard, learning goal

**Info card**:
The panel of Turkish text, key facts and sources shown for a selected organelle at a chosen level.
_Avoid_: Tooltip, popup, detail page

### Citations

**Source**:
A cited reference (MEB program, Wikipedia page, open textbook, Commons file) with URL, author/publisher and license.
_Avoid_: Reference, link, citation (as a noun for the record itself)

**Bibliography**:
The generated page listing every Source used anywhere in the site.
_Avoid_: References page, credits

**Micrograph**:
A real microscope image (light or electron) shown beside the 3D model, always with its Source and license.
_Avoid_: Photo, picture

### 3D exploration

**Cell scene**:
The assembled 3D view of one cell type: its shell plus all its placed organelles.
_Avoid_: Viewer, canvas, world

**Shell**:
The outer boundary of a cell type (membrane, plus wall where present) that can be cut open.
_Avoid_: Skin, outline

**Placement**:
The data that says where, how large and how oriented an organelle instance sits in a cell scene.
_Avoid_: Layout, transform

**Cutaway**:
A view where a clipping plane removes part of the shell and organelles, with a capped interior so the cut looks solid.
_Avoid_: Slice, cross-section toggle

**Isolate**:
Showing one organelle alone, hiding all others.
_Avoid_: Solo, focus

**Comparison**:
Two cell scenes shown side by side with linked camera, highlighting shared and different organelles.
_Avoid_: Diff, versus mode

### Modules, labs and simulations

**Timeline module**:
A module whose picture is a pure function of time (`seek(t)`): phases, a scrub bar, charts and checks (mitoz ve mayoz, enerji, kas ...). Defined by `ModuleInfo` plus a `ModuleScene`.
_Avoid_: Animation module, video

**Track**:
One animation of a timeline module, shown as a tab (e.g. mitoz, mayoz I). In the chemistry lab each track explains one experiment and has the experiment's id.
_Avoid_: Scene, episode

**Phase**:
A named stretch of a track with its own text per level, chart points and step button.
_Avoid_: Chapter, slide

**Sim module**:
An interactive sandbox with fixed-step simulation state instead of a timeline: sliders, drag and drop, measurements, snapshot and restore. Contract `SimScene` (`docs/SIMS.md`); the chemistry lab is the first, physics sandboxes will follow (research in `docs/research/fizik.md`).
_Avoid_: Game, widget

**Time-lapse (zaman atlaması)**:
The factor (1x, 5x, 20x, 60x) by which a sim runs faster than real time; the step grows instead of the frame count.
_Avoid_: Fast forward, speed multiplier

**Kimya laboratuvarı**:
The chemistry sim module: ten guided experiments (Rehberli deney), a free bench (Serbest tezgâh), the engine in `src/chemlab` and the 3D bench in `src/modules/chem-lab`.
_Avoid_: Chem game

**Defter**:
The lab notebook: the engine's timestamped journal (actions, observations, measurements, warnings) shown in the lab, with a copy button; clicking a line replays that moment.
_Avoid_: Log, report

**Nedenini göster**:
The particle-level explainer of an experiment, played as a timeline track after the steps are done.
_Avoid_: Explanation video

**Sorular**:
The setting (Açık / Kapalı) that decides whether Kendini dene checks and Tahmin et prompts pause the animation; "Kendini dene" is the list of questions and stays reachable when it is off.
_Avoid_: Quiz mode

**Safe area**:
The part of the stage not covered by floating panels; the camera centres the picture in it (`setSafeInsets`). Narrow stages (under about 1450 x 740 px) switch to a compact layout.
_Avoid_: Margin, viewport

### Asset pipeline

**Organelle asset**:
The GLB file of one organelle with named nodes and three levels of detail, generated by a Blender script.
_Avoid_: Model, mesh file

**Generator**:
A Blender Python script that produces organelle assets reproducibly from data.
_Avoid_: Exporter, builder script

**Quality gate**:
The side-by-side check of generated assets against the reference look; failing it triggers the fallback asset research.
_Avoid_: Review, bake-off (informal name only)
