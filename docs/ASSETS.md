# Organelle asset contract (GLB)

Generated by Blender scripts in `tools/blender/` (ADR 0001), consumed by `src/scene`. A test (`tests/assets.test.ts`) enforces this contract.

## Files
`public/models/organelles/<id>.glb` plus `<id>.meta.json`. Ids (kebab-case, equal to `OrganelleInfo.id`):

Eukaryote: `nucleus`, `mitochondrion`, `rough-er`, `smooth-er`, `golgi`, `ribosome` (one small cluster of 6–10 granules), `lysosome`, `centrosome`, `vacuole`, `chloroplast`.
Prokaryote: `nucleoid`, `plasmid`, `flagellum`, `pilus`.
Shells (hollow, nested closed surfaces): `membrane-animal`, `membrane-plant`, `wall-plant`, `envelope-bacterium` (membrane + wall + capsule layers as separate meshes).
`ribosome` is reused by the bacterial scene.

## Space and size
Y-up, right-handed, 1 unit = 1 µm with mild exaggeration for legibility (nucleus diameter ≈ 6, mitochondrion ≈ 3.2 × 1.2, chloroplast ≈ 5 × 2.4, golgi stack ≈ 3.5 wide, lysosome ≈ 1.1, centrosome pair ≈ 1.6 long). The asset is centred on its bounding-box centre at the origin.

## Nodes
Root node `<id>`; children `LOD0`, `LOD1`, `LOD2` (the app toggles `.visible`). Names use letters, digits, `_`, `-` only. Mesh names are `<id>-<part>` (e.g. `nucleus-envelope`, `nucleus-nucleolus`); the app treats the whole organelle as one selectable unit.

## Materials
At most 2 per file, identified by name suffix; the app replaces them with shared materials, so authored values only matter as fallbacks:
- `<id>_clay`: opaque, colour comes from **vertex colour `COLOR_0`** (baked colour variation and ambient occlusion), soft satin finish.
- `<id>_gel`: translucent (membranes, vacuole, capsule); vertex colour carries tint and alpha.
UVs: tiling cube-projected UVs (metres-free, 0–1 per 2 µm) so one shared micro-normal map can be applied.

## Geometry rules
- Every mesh is a closed (watertight, manifold) surface so the stencil cutaway cap works; hollow shells are two nested closed surfaces.
- Budgets (triangles): LOD0 ≤ 60 000, LOD1 ≤ 30 % of LOD0, LOD2 ≤ 60 % of LOD1 (LOD2 ≥ 300). Whole eukaryote scene must stay below about 1.2 M triangles at LOD0 with all instances; prefer instancing in the app.
- Smooth normals with the detail in geometry (cristae, cisternae, pores, ridges), not in textures.
- GLB size ≤ 1.5 MB each, meshopt compression, no embedded textures (colour is in vertices).

## meta.json
`{ "id", "tris": {"LOD0","LOD1","LOD2"}, "bboxMin":[x,y,z], "bboxMax":[x,y,z], "boundsRadius", "closed": true, "generator": "<script>", "seed": n }`. The layout solver reads `boundsRadius`.

## Reproducibility
Generators are deterministic (fixed seeds); re-running overwrites outputs byte-identically. They run headless: `blender -b --factory-startup --python tools/blender/make_organelles.py -- IDS=nucleus,golgi`. Use only `bpy`, `bmesh`, `numpy`, `mathutils`.
