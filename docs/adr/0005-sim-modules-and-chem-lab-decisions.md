# Interactive simulation modules (SimScene) and the chemistry lab decisions

Timeline modules (`ModuleScene`, pure function of time) cannot take sliders or drag and drop, so interactive labs use a second contract, `SimScene` (`docs/SIMS.md`): fixed-step deterministic state, typed parameters, measurements, snapshot/restore. The chemistry lab (`chem-lab`) is the first sim module; physics sandboxes will reuse the contract. Decisions taken from `docs/research/kimya-lab.md`: one module with ten guided experiments plus a free-play bench (not ten modules); the lead-iodide experiment is replaced by a safe calcium carbonate precipitation, magnesium combustion stays virtual with a visible safety note; experiments the programme does not name are allowed only as labelled 'Ek bilgi'; the chemistry engine is a pure, tested TypeScript rule engine separate from rendering; no sound in the first release; Defter (lab notebook) is in-app only (no print/PDF); a Turkish chemistry teacher should review the texts before wider use (not arranged by us).
