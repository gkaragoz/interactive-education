## MEB programmes

Official public curriculum documents of the Turkish Ministry of National Education (Türkiye Yüzyılı Maarif Modeli). We cite them for kazanım codes and the grade-level limits (for example FB.8.3.3: at grade 8 mitosis and meiosis are compared without entering the phases); `summaryTr` of each kazanım is our paraphrase, not the official text.

- [Fen Bilimleri Dersi Öğretim Programı (3, 4, 5, 6, 7 ve 8. Sınıflar)](https://tymm.meb.gov.tr/assets/pdf/fen-bilimleri-dersi_20260902_111309_119.pdf), T.C. Milli Eğitim Bakanlığı, Talim ve Terbiye Kurulu Başkanlığı, MEB (resmi program), tr, verified 2026-10-23 (`meb-fen-2026`)

## How to add a source

1. Open the page in a browser or fetch it and confirm it exists and says what you cite it for. Do not cite a page you have not opened.
2. Add an entry to `src/data/sources.ts`: use the `wpTr`, `wpEn`, `openstax` or `commons` helper where possible. `id` is kebab-case with a prefix (`wp-tr-`, `wp-en-`, `os-`, `commons-`, `meb-`). Set the real licence (read it from the page, do not assume) and `accessed` to the date you checked.
3. Reference the id from `sourceIds` of the organelle, cell, module or kazanım that uses it. Write the text in your own words. Every module fun fact must cite a source that is also listed in the module's `sourceIds`.
4. For a micrograph: read author and licence from the Commons file page; accept only CC BY, CC BY-SA, CC0 or public domain; resize to at most 900 px wide as WebP at about 150 KB or less into `public/micrographs/`; add a `commons` Source and an entry in `src/data/micrographs.ts` with the same licence string.
5. Run `npm test`; `tests/data.test.ts` and `tests/modulesData.test.ts` check ids, https URLs, licences, references and that micrograph files exist.
6. Add the entry to this page (grouped by kind) in the same change.
