## How to add a source

1. Open the page in a browser or fetch it and confirm it exists and says what you cite it for. Do not cite a page you have not opened.
2. Add an entry to `src/data/sources.ts`: use the `wpTr`, `wpEn`, `openstax` or `commons` helper where possible. `id` is kebab-case with a prefix (`wp-tr-`, `wp-en-`, `os-`, `commons-`, `meb-`). Set the real licence (read it from the page, do not assume) and `accessed` to the date you checked.
3. Reference the id from `sourceIds` of the organelle, cell or kazanım that uses it. Write the text in your own words.
4. For a micrograph: read author and licence from the Commons file page; accept only CC BY, CC BY-SA, CC0 or public domain; resize to at most 900 px wide as WebP at about 150 KB or less into `public/micrographs/`; add a `commons` Source and an entry in `src/data/micrographs.ts` with the same licence string.
5. Run `npm test`; `tests/data.test.ts` checks ids, https URLs, licences and that micrograph files exist.
6. Add the entry to this page (grouped by kind) in the same change.
